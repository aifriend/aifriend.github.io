# aifriend.github.io

This repository is the source of the GitHub Pages site served at https://aifriend.github.io/. It is plain static HTML with no build step, so every file is published exactly as it appears in the repository.

## What each path publishes

| Path | Live URL | What it is |
|------|----------|------------|
| `index.html` | https://aifriend.github.io/ | The landing page. It describes MindForge, a brain-training app for working memory on iPhone and iPad, and links to the support and privacy pages. |
| `mindforge-support/index.html` | https://aifriend.github.io/mindforge-support/ | The support page for the MindForge app. |
| `mindforge-privacy/index.html` | https://aifriend.github.io/mindforge-privacy/ | The privacy policy for the MindForge app. |
| `.nojekyll` | not served as a page | An empty marker file that tells GitHub Pages to serve the files as they are, without running Jekyll. |

## Editing

Edit the HTML files directly and push to the default branch, `main`. GitHub Pages redeploys the site automatically.
